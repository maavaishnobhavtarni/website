# Sacred Mandir Video Instructions

Place your official temple video file in this folder with the exact filename:

```text
temple-video.mp4
```

### Video File Details:
- **Filename**: `temple-video.mp4`
- **Format**: MP4 (H.264 / AAC recommended for universal web and mobile browser playback)
- **Path in repository**: `assets/videos/temple-video.mp4`
- **Poster Image**: `assets/images/maa-darshan.jpg` (automatically shown before play)

As soon as you upload `temple-video.mp4` into this folder on your GitHub repository, the website video player will automatically stream your video!
